# Historical PR379 cinematic product candidates

These exact 20 files were moved from `storefront/public/cinematic-preview/`
on 2026-11-04 because the current scene comparison uses the original public
photographs. Every file is byte-identical to its previous version. The adjacent
`manifest.json` records its prior path, product ID/name, SHA-256 and byte count.
Git records each as a 100% rename. No cover, logo or menu texture was moved.

The previous [asset inventory](../../BIZBOT_STOREFRONT_CINEMATIC_001_ASSETS.md)
records 16 files as AI background extraction with reconstructed details, and
four (Cola, Sprite, Sprite zero, XL) as optimized original transparent images.
Those descriptions are preserved individually in the manifest. These are
historical review candidates, not newly approved production cutouts.

Keeping the unused originals outside deployed `public/` preserves the prior
design work without shipping a duplicate product set or raising the existing
static output budget. The current self-contained review photographs and their
provenance are described in [the Preview note](../../STOREFRONT_VISUAL_PARITY_PREVIEW.md).
